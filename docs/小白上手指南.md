# 📱 小白上手指南（AI 增强版阅读）

> 本指南面向第一次接触这个项目的人，目标是：**把 App 装到手机上 → 配好 AI → 用起来**。

---

## 一、这是什么？

这是知名开源阅读器「阅读3.0」（legado）的 **AI 增强改造版**：

- 原版功能全部保留：网络书源 / 本地书籍 / 书架管理 / 朗读 / RSS 订阅
- 新增了 **AI 智能助手**：
  - 🤖 自由对话 + 小说领域技能（搜书、章节总结、人物分析、书源诊断修复）
  - 🛠️ Agent 能真实操控 App：帮你搜书、打开书、管理书架
  - 🔒 所有危险操作（如修改书源）必须你二次确认才会执行

## 二、安装 APK（3 分钟）

成品已经编译好了，就在仓库里：

```
ai-apk-download/legado-ai-apk/legado_ai_3.26.082315-ai-v2.apk
```

**步骤：**
1. 把这个 APK 文件传到手机（微信文件传输助手 / 网盘 / 数据线都行）
2. 手机上点开安装。如果提示"未知来源应用"，允许即可
3. 安装成功后桌面会出现阅读 App 图标

> ⚠️ 注意：手机上如果已装过原版阅读，这个版本的包名不同
> （`io.legado.ai.release`），可以共存，数据不互通。

## 三、配置 AI（关键一步！）

打开 App → 我的 → **AI 智能助手配置**（或在 AI 助手页点右上角 ⚙）：

1. **服务商预设**：已内置 13 家可选——DeepSeek、通义千问、智谱 GLM、Kimi、
   硅基流动、MiniMax、豆包、OpenAI、OpenRouter、Groq、xAI、Ollama 本地、LM Studio 本地
   （选好后 Base URL 和模型名会自动填充）
2. **API Key**：去所选服务商官网注册并创建（一串 `sk-` 开头的字符），粘贴进来
3. 点 **「测试连接」**：显示 ✓ 即配置成功
4. 进 AI 智能助手对话页，发一句"你好"试试

> 💡 API Key 是加密存储在手机上的，不会明文泄露。建议先开启系统锁屏。
> 💡 入门推荐 DeepSeek 或智谱 glm-4-flash（免费）。

## 四、开始使用

进入 **AI 智能助手中心页**后你可以：

1. **自由对话**：底部输入框直接问；气泡式界面，长按可复制回答
2. **快捷指令**：输入框上方一排按钮——总结当前章节 / 找书 / 分析人物 / 诊断书源 / 看书架
3. **实时工具卡片**：AI 调用工具时会显示「⏳ 执行中 → ✅ 完成(耗时)」卡片
4. **操控 App**：说"帮我把《XXX》加到书架"、"打开《XXX》"，会真实跳转
5. **修书源**：让它诊断失效书源——修复方案会以「🔐 写操作待确认」卡片出现，
   **你点"同意执行"才会真正修改**
6. **多会话**：顶栏「会话」按钮可切换/删除历史会话，「＋」新建；重开 App 自动续接最近会话

## 五、⚠️ 法律与安全提醒（务必阅读）

- 原版 legado 已因盗版侵权问题被作者主动清空代码并发公告
- 请只使用**正版/授权书源或本地书籍**，不要导入来路不明的盗版书源
- AI 的写操作都有确认机制，看不懂的弹窗先别急着点"同意"
