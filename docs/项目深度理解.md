## 3. AI 平台层（fork 核心增量）

### 3.1 装配与配置

- **AiPlatform.init()**（App.onCreate 调用，单次）：构造 4 个 Default* bridge → `buildRegistry(bridge)` 注册 22 工具 → `syncConfig()`。
- **AiPlatform.syncConfig()**：配置变化才重建 `OpenAIClient + AgentRuntime`；bridge/registry 不随配置重建。防御式读取（坏配置沿用旧值），可在 onResume 高频调用。触发点：AgentHub onResume。
- **ModelManager.getConfig()**：SharedPreferences 逐字段读取（`PreferKey.aiBaseUrl/aiModel/aiStream/aiTimeout/aiMaxRounds/aiSessionWindow/aiToolProtocol` 共 15 个 ai_* 键）+ AiKeyStore 取 Key。`prefStringSafe/prefBooleanSafe` 类型异常即删键自愈——防 ClassCastException 击穿页面（历史事故修复）。
- 预算硬编码：`maxTokens = 16_000L`（AiPlatform.kt:83），配置里的 maxTokens 字段未参与控制。

### 3.2 AgentRuntime 执行循环（ai/runtime/AgentRuntime.kt）

外层 `repeat(maxRounds)`（默认 5）：

1. stopRequested 检查 → STOPPED；
2. `completeOnce()`：text 协议不发 tools schema；可重试错误退避重试 1 次；流式走 SSE 增量写 `ctx.onPartialText`（打字机）；
3. 无原生 tool_calls 且协议≠native 时 → **TextToolCallParser 从回答文本解析 XML 工具调用**（Operit 兼容层核心），命中则替换 calls 并剥离标签；
4. 追加 assistant(content+tool_calls) 消息；
5. 计费累计（usage 缺失按 `256+len/3` 估）超 16k → BUDGET_EXCEEDED 截断；
6. 无工具调用 → DONE。

内层**三阶段工具流水线**：①整批 resolve（查注册表/JSON 解析/必填校验，参数统一转 Double/String）→ ②并行 invoke（45s 超时，写操作绝不自动重试）→ ③按原序回填 role=tool 消息。

**写操作 pending_confirm 状态机**：工具返回 PENDING_CONFIRM → 发 PHASE_CONFIRM 事件 + `ctx.onConfirmRequested = ConfirmRequest(callId, args)`（**token 就是 tool_call id**）→ `awaitApproval()` 从 Channel 收 UI 决策，token 不匹配丢弃继续等，**超时（=timeoutMillis 默认120s）或停止均按拒绝处理** → 同意才执行 `def.onApproved(ctx,args)` 真正落库；拒绝回填 NO_PERMISSION。UI 入口 `AgentRuntime.approve(token, approved)`。

### 3.3 工具调用三协议（Operit 移植）

- `auto`（默认）/`native`/`text`，键 `aiToolProtocol`；
- text/auto 模式由 SystemPromptBuilder 向系统提示注入 XML 协议说明 + 全量工具清单；
- TextToolCallParser：`<tool name="x"><param name="k">v</param></tool>` 正则解析 + CDATA/实体还原 + 代码围栏剥离 → 还原为与原生一致的 ToolCallData，主循环无感复用同一流水线（含确认机制）。

### 3.4 22 个工具矩阵（ToolRegistryFactory.buildRegistry）

| 分类 | 工具 | 写🔐 | 备注 |
|------|------|------|------|
| 选书 | search_books(keyword,limit≤20)、recommend_books(=search(name,5)) | | 跨前 6 个启用源并行搜，单源限时 8s，按名去重 |
| 读书 | read_chapter、summarize_chapter、plot_recap | | 三者**同一实现**（读正文>4000字头3200尾800截断） |
| 懂书 | analyze_characters、analyze_theme（同读章实现）、explain_text（占位：仅回显 preset 正文前500字，解释靠模型自身） | | |
| 书源 | analyze_book_source 与 get_source_rules（完全同实现）、list_book_sources(截50)、get_source_stats、test_book_source(实测搜"我的"15s) | | |
| 书源🔐 | suggest_source_fix（⚠️批准后什么都不做，见 §7）、set_source_enabled(onApproved 写库) | 🔐 | |
| 书架 | list_shelf、open_book(发 AppNav.OpenBook 导航)、remove_book(onApproved 真删库)、open_search、open_bookshelf | remove_book🔐 | 导航三件套经 sharedCtx.onNavigate 由 Hub 消费跳页 |
| 设置 | get_setting、set_setting(白名单 nightTheme/threadCount 1..32/showRss) | set_setting🔐 | |

manualConfirm=true 共 4 个：remove_book / suggest_source_fix / set_source_enabled / set_setting。`toOpenAiSchema()` 自动给写工具描述追加确认提示。

### 3.5 Bridge 层（读写分离的领域桥）

接口：BookFetcher / ChapterReader / BookSourceAnalyzer / SourceRuleWriter（**无实现，纯声明**）/ AppController(+AppNav 密封类)。设计意图：①AI 不直接依赖 WebBook/DB，返回标准化 Map 可 mock 可替换；②横切关注点收敛（超时预算 8s/15s、日志、异常吞噬集中一处）；③只读/写能力分离，写必须过确认流水线。

### 3.6 环境化 AI：任务中心 + 悬浮球 + 过程折叠

- **AgentTaskCenter**（进程级 SupervisorJob scope，**无 Android Service 组件**）：单任务槽；共享 sharedCtx 让工具卡/确认/流式增量跨页面回流，Hub 重进自动重绑；>3s 完成发系统通知点击回 Hub。dispose 不停任务，切会话 ensureIdle 强制停防串写。
- **AIFloatBallView**：声明式挂载于 activity_book_read.xml:41（PageView 兄弟节点），8dp 拖拽阈值、220ms 贴边吸附+半透明、位置按边+纵向比例记忆；点击携 preset_book/preset_chapter 开 Hub。另一入口 ReadMenu.fabAiAssistant 额外传整章正文 preset_content。
- **思考过程折叠**：每用户回合内工具卡/错误条归组到「▸ 工作过程·N步」，确认卡永远外显（安全底线）。

### 3.7 Hub UI 渲染管线

轮询+差分而非 Flow collect：Activity 90/150ms 循环组装行列表 → renderIfChanged 三级差分（引用相等→单行 notify→全量）；VM 80ms 合并工具事件卡（自增 eventSeq 防 StateFlow conflation 吞事件）、120ms 确认卡。6 种 ViewType（用户/AI 气泡带时间戳、工具卡、错误条、确认卡、折叠头）。背景三明治：AuroraBackgroundView（极光渐变，60s 动画退后台停帧）/ 自定义图片 / scrim 遮罩。

### 3.8 持久化与日志

- 会话：Room `aiSessions`/`aiMessages`（DB v19→20 迁移新增）；消息 kind 区分 user/assistant/tool_call/tool_result…，payload 存 JSON；seq=maxSeq+1；超 12000 字符从头裁剪。**注意 loadChat 的 window SQL 取的是最早的 N 条（bug，见 §7）**。
- 配置：15 个 SharedPreferences 键；API Key 设计上走 AiKeyStore（AndroidKeyStore AES/GCM，别名 legado_ai_key）——**但加密链路当前是死的（§7 第1条）**。
- AiLog：内存环形 800 条 + filesDir/logs/ai.log（512KB 轮转）双写，mask() 脱敏；日志页 🐛 1s 轮询渲染 500 条，可复制/清空/分享完整文件（>1200 行截尾规避 Binder 1MB）。

## 4. 上游基座（业务核心层）

### 4.1 规则引擎（legado 灵魂）

- **AnalyzeRule**(646行)：统一门面，Mode{XPath,Json,Default,Js,Regex}；splitSourceRule 切段处理 `@put:`/`##正则净化`/`{{js}}`/`@get:{}`/`$N`；变量上下文 chapter/book.variableMap(JSON 存 Room)；JS=Rhino 绑 java/result/baseUrl。
- 后端四件套：AnalyzeByJSoup(class./tag./id./text./children/!排除/>过滤/@链式/&& %% ||)、AnalyzeByJSonPath(Jayway+{$.}内嵌)、AnalyzeByXPath(Seimi)、AnalyzeByRegex(:开头多段)。
- **AnalyzeUrl**(455行)：URL option 语法（`@js:`/`<js>`/`{{}}`/页码表/`,{...}` method/charset/webView/headers/body）→ Retrofit(HttpHelper) 或 AjaxWebView(EvalJs/嗅探双模式)。
- ⚠️ 无 RuleAnalyzer（上游后期才有）；规则重复解析无缓存。

### 4.2 WebBook 流水线

searchBook/exploreBook/getBookInfo/getChapterList/getContentSuspend → BookList(bookUrlPattern 详情页兜底) → BookInfo → BookChapterList(nextTocUrl 单链串行 / 多链并发+synchronized finish()) → BookContent(正文翻页 nextUrl while 串行)。搜索并发：SearchBookModel fixedThreadPool(threadCount 默认16)+30s timeout。

### 4.3 本地书 / 存储 / 网络 / 朗读

- 本地书仅 **TXT**(EncodingDetect+512KB 分块正则分章) 与 **EPUB**(epublib)；无 mobi/pdf。
- 存储：book_cache/<书>/章节.nb+images/、covers/、backup/；无 Directory 分层类。
- 网络：HttpHelper 单例 OkHttp（15s/trust-all SSL/CLEARTEXT/HTTP_1_1）+ 按 baseUrl 动态 new Retrofit（EncodeConverter BOM 探测）；支持 http/socks 代理；CookieStore 双身份(Room 子域键+PersistentCookieJar)。
- 朗读：BaseReadAloudService 抽象(MediaSession/焦点/通知/定时) → HttpReadAloudService(自配 TTS API 合成 mp3 边下边播) / TTSReadAloudService(系统 TTS+onRangeStart 高亮)。

## 5. UI / Service / Web / API 层

### 5.1 入口与导航

WelcomeActivity(LAUNCHER，500ms 进主界面) → MainActivity(ViewPager 四 Tab：书架/发现/RSS/我的) → BooksFragment.open() 按 BookType 分发 ReadBookActivity / AudioPlayActivity。fork 触点：MainActivity 读 extra `agent_select_tab`（AI 反向切 Tab）、ConfigActivity 第 4 分页 AiConfigFragment、MyFragment 两个 AI preference 入口。

### 5.2 阅读页（最复杂单体）

- ReadBookActivity 866 行挂 12 个 CallBack 接口 + 单例引擎 service/help/ReadBook.kt：三章缓存窗口(cur±1 同时加载排版)，翻章时 GlobalScope 预取 ±10 章（只下载不排版）。
- 渲染：PageView(三 ContentView) → ContentTextView 逐 TextChar 自绘 → ChapterProvider(object 全局排版：StaticLayout 分行+两端对齐+图片段)；翻页 5 种 PageDelegate(仿真/覆盖/滑动/滚动/无动画)+Scroller。
- 菜单 ReadMenu 浮层卡片化(fork 圆角改造)，亮度条/夜间 FAB/fabAiAssistant。
- 生命周期：onPause 存进度+上传+自动备份；息屏定时器控常亮；TextActionMenu 选中文字可一键建替换规则。

### 5.3 Service 清单（6 个，startService 型 + LiveEventBus/companion 通信）

WebService(NanoHTTPD 1122+WS 1123)、DownloadService(threadCount 并发下载)、BaseReadAloudService→Http|TTS、AudioPlayService(有声书)、CheckSourceService(批量验源，失败打"失效"分组)。

### 5.4 内置 Web 服务与 Provider

REST 9 条路由（getSources/getSource/getBookshelf/getChapterList/getBookContent/saveSources/deleteSources/saveBook 等，ReturnData 包装+CORS 全开）；WS `/sourceDebug` 供 PC 编辑器实时调书源；assets/web 是 Vue SPA 门户。ReaderProvider(authority=`${applicationId}.readerProvider`，exported=true 无权限保护) 复用同套 controller 返回伪 Cursor JSON。

### 5.5 事件体系与基类

LiveEventBus（19 个 tag 常量，post≈98/observe≈35 处），并存 MutableLiveData 直连/callBack 直调/静态标志位；无 Flow。BaseActivity(BaseVMActivity/BasePreferenceFragment) 封装主题沉浸/菜单染色/MainScope 协程；权限用自研 help/permission DSL。

## 6. 构建体系与 CI

### 构建矩阵

| flavor | applicationId | 说明 |
|--------|--------------|------|
| app | io.legado.app(.release/.debug) | 原版 |
| google | io.legado.play | Play 版（需 google-services.json 才能编译） |
| ai（主线） | io.legado.ai(.release/.debug) | AI 共存版 |

签名：读 gradle 属性 RELEASE_STORE_FILE/PASSWORD/KEY_ALIAS/KEY_PASSWORD；**keystore 明文提交在 .github/workflows/legado.jks**（alias=legado）；无属性时 release=unsigned 不可装。minifyEnabled=false。产物 `app/build/outputs/apk/<flavor>/<bt>/legado_<flavor>_<version>.apk`；仓库内 ai-apk-download/(v5757) 为人工 release 提交。

本地命令：`./gradlew assembleAiRelease|assembleAiDebug|testAiDebugUnitTest`；前置 JDK 8~11 + SDK android-29 + build-tools 29.0.3。

CI 4 workflow（均无 Secrets，产物只传 Actions Artifact 不自动入库）：ai-build.yml(push master 过滤路径，注入 jks 出签名包)、android.yml(全量，浅克隆致 versionCode 失真)、legado.yml(release/tag/cron，改包名共存 hack)、autoupdatefork.yml(**每日盲 merge 上游——风险点**)。

依赖要点：jsoup/JsoupXpath/json-path(规则三件套)、rhino-android(JS)、retrofit+PersistentCookieJar、Room 2.2.5(kapt)、Glide、live-event-bus-x、NanoHTTPD+NanoWSD(web+Vue SPA)、hanlp(简繁)、epublib、desugar。

资源分区规律（改 UI 时定位）：AI 定制三层隔离——`ai_` 前缀资源(colors_ai.xml 亮暗成对/layout ai_item_*+activity_agent_hub/drawable ai_bg_*+ic_ai_*/pref_config_ai.xml)、flavor 源集 src/ai/res(仅 app_name)、代码全在 main 源集 io.legado.app.ai/。

## 7. 技术债优先级清单（跨报告汇总，按严重度）

> 状态更新 2026-08-24：P0 全部修复（`26e64265e`）；P1 第 4~9 条全部修复（`ed991c457`）。

### P0 — 功能性缺陷（承诺了但没生效）✅ 已修复

1. ✅ **API Key 加密死链路**：AiKeyStore 读取时自愈迁移明文；配置页拦截写入改走 Keystore；测试连接/摘要统一读加密值。
2. ✅ **suggest_source_fix 有确认无落地**：新增 DefaultSourceRuleWriter（白名单字段合并写回）接入 AiBridge；工具支持 changes 参数，onApproved 真正写库。
3. ✅ **会话窗口取向反了**：DAO 改 windowLatest(DESC)+reversed，取最近 N 条。

### P1 — 行为不一致/易踩坑 ✅ 已修复

4. ✅ 非流式 complete() 补 HTTP 状态码检查：非 2xx → AUTH_FAILED，与流式路径一致。
5. ✅ 确认窗口独立于请求超时（至少 5 分钟），后台任务不再轻易被动拒绝。
6. ✅ search_books 书源随机抽取 + 文案修正（5→6），消除头部源偏置。
7. ✅ text 协议消息形状降级：tool 角色→user、tool_calls 还原 XML 正文、不发 tools schema/tool_call_id。
8. ✅ 确认通道改共享 ApprovalBus：runtime 重建不丢未决确认，广播+token 过滤天然清理过期请求。
9. ✅ 停用 autoupdatefork 每日盲 merge，改为仅手动触发。

### P2 — 上游遗留（fork 未引入但需知）

10. ReadBook.callBack 强引用 Activity 从不置 null（泄漏）；GlobalScope 预取不可取消。
11. ReaderProvider exported 无权限保护；Web 服务零鉴权 CORS 全开（局域网任意读写书架书源）。
12. trust-all SSL、每次 new Retrofit、规则重复解析无缓存、synthetic 废弃。
13. 轮询架构（80~150ms busy-poll StateFlow.value）功耗空转。
14. ad hoc CoroutineScope 泄漏隐患（AiBridgeImpl 三处 new scope 永不 cancel）。
15. 测试覆盖薄：仅 parseCompletion(5例)+错误码(3例)；AgentRuntime/Parser/Executor 无单测。
